SmartSupply: Einkaufslisten-Import bricht ab 1001 Positionen ab

Behoben Erledigt SmartSupply Version 5.28.0 #496

Abgeschlossen am 06. August 2026

Der Import auf die Einkaufsliste baut ein einziges INSERT INTO dbo.tArtikelEinkaufsliste ... VALUES mit einer Zeile pro Position (Modules/SmartSupply/ViewModels/SmartSupplyViewModel.cs, Zweig config.ImportType != 0).

SQL Server erlaubt maximal 1000 Zeilenwerte pro VALUES-Liste. Ab 1001 Positionen bricht der Import mit "Die Anzahl der Zeilenwertausdrücke in der INSERT-Anweisung überschreitet die maximal zulässige Anzahl von 1000 Zeilenwerten" ab. Betroffen sind genau die Kunden mit großen Sortimenten, bei denen SmartSupply seinen Nutzen hat.

Erschwerend: Das Statement wird per String-Verkettung gebaut. Bei mehreren Tausend Positionen entsteht ein Statement von mehreren hundert Kilobyte, das SQL Server jedes Mal neu parsen muss.

Erwartetes Verhalten

Die Positionen werden in Blöcken eingefügt, deren Größe unter der Grenze bleibt, mit Parametern statt eingesetzten Werten. Der Aufbau der Statements gehört in eine eigene, testbare Einheit statt in die ViewModel-Methode.
