Arpatools Sammelrechnung weist den Gewinn von Aufträgen nun korrekt aus

Geplant Offen Sammelrechnung Ohne Version #327

Erstellt am 17. April 2026

Ausgangssituation:

  • Wen nein Aufträg über Sammelrechnung abgerechnet wird, wird im Ursprungsauftrag eine Rabattposition je Steuersatz generiert.Das sorgt dafür, dass der Auftrag ausgeglichen (bezahlt) ist. Die Positionen werden als Freipositionen in einen Sammelauftrag überführt.

Nun ist es so, dass die Einkaufspreise im urpsungsauftrag nicht genullt werden. Das sorgt dafür, dass der Auftrag einen negativen Gewinn ausweist.

Zukünftig wird auch der EK-Preis der Position auf 0 gesetzt. Der EK der Position soll in den Sammelrechnungsauftrag überführt werden.

Einstellungen: Per Option kann das alte Verhalten wiederhergestellt werden: - Einkaufspreise in Sammelrechnung übernehmen? Default =JA

Erster Programmstart: Diese Prüfung soll ausschließlich bei Erstellung der von neuen Sammelrechnungen integriert werden. Alte Aufträge bleiben unberührt.

Das SQL zur optionalen RÜckwirkenden Bearbeitung von alten Aufträgen steht über den Support zur Verfügung.
