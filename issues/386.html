Jobby Aktion: Daten per SQL einfügen/ändern klappt nur bedingt

Behoben Erledigt Jobby Version 5.11.0 #386

Abgeschlossen am 17. April 2026

Bei der Aktion Daten per SQL einfügen/ändern gibt es die regel, dass ein Benutzer admin sein muss.

ein admin definiert sich in Arpatools dadurch, dass er Mitglied einer Benutzergruppe ist, die Benutzer anlegen und ändern darf. Das funktioniert in der aktuellen Version nicht, wenn es sich bei dem verwendeten Benutzer nicht um den original Admin handelt.

Szenario zum reproduzieren:

  • einen neuen Benutzer anlegen und der Benutzergruppe Administrator hinzufügenb
  • Aktion Daten per SQL einfügen/ändern zu einem neuen Job hinzufügen
  • Verfikation Versuch mit dem neuen Benutzer
